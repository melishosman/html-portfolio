# HTML Portfolio Project

A clean and simple multi-page portfolio website built entirely using semantic **HTML5**.

## 🌐 Live Demo
You can view the live site here:  
👉 [Live Demo](https://melishosman.github.io/html-portfolio/)

## 📌 Projects Included
* **Movie Ranking Project:** A curated list of my top favorite movies with brief personal reviews.
* **Birthday Invite Project:** A sample birthday party invitation page featuring event details and location links.
* **About Me & Contact Pages:** A personal introduction and a sample contact page template.

## 🛠️ Built With
* Pure HTML5 (headings, lists, image elements, anchor links, and relative path navigation)
